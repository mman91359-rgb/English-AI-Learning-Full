● 完整表结构详解

  ---
  一、user_db（用户与画像库）

  1. sys_user — 用户账户表

  负责功能： 注册、登录、JWT认证、个人信息管理

  ┌───────────────────────┬────────────────────┬──────────────────────────────────┐
  │         字段          │        类型        │               作用               │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ id                    │ BIGINT PK          │ 用户唯一标识，全局使用           │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ username              │ VARCHAR(50) UNIQUE │ 登录账号                         │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ password              │ VARCHAR(255)       │ BCrypt加密密文（work factor=12） │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ nickname              │ VARCHAR(50)        │ 显示昵称                         │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ avatar_url            │ VARCHAR(255)       │ 头像地址                         │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ cet_level             │ VARCHAR(10)        │ 考试目标：CET4 或 CET6           │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ roles                 │ VARCHAR(100)       │ 角色：ROLE_USER / ROLE_ADMIN     │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ status                │ TINYINT            │ 1=正常, 0=禁用                   │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ last_login_at         │ DATETIME           │ 最后登录时间                     │
  ├───────────────────────┼────────────────────┼──────────────────────────────────┤
  │ created_at/updated_at │ DATETIME           │ 审计时间戳                       │
  └───────────────────────┴────────────────────┴──────────────────────────────────┘

  关联关系：
  sys_user (1) ──── (1) user_ability_radar    [同库，user_id唯一约束]
  sys_user (1) ──── (N) user_exercise_log     [跨库，通过user_id关联]
  sys_user (1) ──── (N) user_error_book       [跨库，通过user_id关联]
  sys_user (1) ──── (N) user_memory_curve     [跨库，通过user_id关联]

  ---
  2. user_ability_radar — 用户能力雷达图表

  负责功能： ELO水平测试结果存储、能力雷达图展示、自适应难度匹配

  ┌──────────────────┬───────────────┬────────────────────────────────┐
  │       字段       │     类型      │              作用              │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ user_id          │ BIGINT UNIQUE │ 1对1绑定 sys_user.id           │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ vocabulary_score │ DECIMAL(5,2)  │ 词汇维度分                     │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ grammar_score    │ DECIMAL(5,2)  │ 语法维度分                     │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ listening_score  │ DECIMAL(5,2)  │ 听力维度分（MVP预留）          │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ reading_score    │ DECIMAL(5,2)  │ 阅读维度分（MVP预留）          │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ elo_score        │ INT           │ ELO综合能力分（默认1000）      │
  ├──────────────────┼───────────────┼────────────────────────────────┤
  │ target_level     │ VARCHAR(20)   │ 能力评级（如"初级/中级/高级"） │
  └──────────────────┴───────────────┴────────────────────────────────┘

  核心作用——驱动自适应选题：
  exercise-service 取题时:
    1. 读取 user_ability_radar.target_level → 确定题目等级范围
    2. 读取 user_ability_radar.elo_score → 匹配难度，使期望得分E在0.4~0.6区间
    3. 前端读取4个维度分 → 渲染 ECharts 雷达图

  二、exercise_db（练习与题库）

  表关系总览

  sys_knowledge_point (知识点树)
         │
         │ N:M via knowledge_mapping
         ↓
  question_info (题目元数据) ─── (1:1) ─── question_content (题目正文)
         │                                        ↑
         │ 通过 question_id 关联                   │ 前后端分离：
         │                                        │ info表用于快速筛选
         ↓                                        │ content表含题干/答案/解析
  user_exercise_log (答题记录)                    │ 只在对应用户答题时才加载
  user_error_book (错题本)

  ---
  3. sys_knowledge_point — 知识点树表

  负责功能： 知识点体系管理、薄弱点诊断、针对性练习

  ┌────────────┬──────────────┬────────────────────────────────┐
  │    字段    │     类型     │              作用              │
  ├────────────┼──────────────┼────────────────────────────────┤
  │ id         │ BIGINT PK    │ 知识点ID                       │
  ├────────────┼──────────────┼────────────────────────────────┤
  │ name       │ VARCHAR(100) │ 知识点名称                     │
  ├────────────┼──────────────┼────────────────────────────────┤
  │ parent_id  │ BIGINT       │ 父节点ID（0=根），形成树形结构 │
  ├────────────┼──────────────┼────────────────────────────────┤
  │ cet_level  │ VARCHAR(10)  │ 所属考试级别                   │
  ├────────────┼──────────────┼────────────────────────────────┤
  │ sort_order │ INT          │ 排序号                         │
  └────────────┴──────────────┴────────────────────────────────┘

  示例树结构：
  语法 (parent_id=0)
  ├── 定语从句 (parent_id=1)
  │   ├── 关系代词 who/which/that
  │   └── 关系副词 when/where/why
  ├── 虚拟语气 (parent_id=1)
  │   ├── 与现在事实相反
  │   └── 与过去事实相反
  └── 倒装句 (parent_id=1)

  词汇 (parent_id=0)
  ├── 核心词汇 (CET4)
  ├── 高频词组 (CET4)
  └── 进阶词汇 (CET6)

  用于薄弱点强化： 统计 user_error_book 中高频错误的知识点 → 针对性推荐该知识点下的题目。

  ---
  4. question_info — 题目元数据表（高频查询）

  负责功能： 题目筛选、列表展示、选题策略（不包含正文，轻量化查询）

  ┌────────────────────┬─────────────┬─────────────────────────────────────────────────────────────────────┐
  │        字段        │    类型     │                                作用                                 │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ id                 │ BIGINT PK   │ 题目ID，全局唯一标识                                                │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ module_type        │ TINYINT     │ 1=词汇，2=语法（决定前端渲染方式）                                  │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ target_level       │ VARCHAR(10) │ 适用考试：CET4 / CET6                                               │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ difficulty_level   │ INT         │ 难度等级 1~8（ELO算法中作为"题目难度分"）                           │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ question_type      │ VARCHAR(30) │ CHOICE(选择) / FILL_BLANK(填空) / TRANSLATION(翻译) / WRITING(写作) │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ knowledge_point_id │ BIGINT      │ 关联主知识点                                                        │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ source             │ VARCHAR(20) │ 来源：MANUAL(人工录入) / AI / IMPORT                                │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ usage_count        │ INT         │ 被使用次数（用于选题去重——避免高频重复）                            │
  ├────────────────────┼─────────────┼─────────────────────────────────────────────────────────────────────┤
  │ is_deleted         │ TINYINT     │ 逻辑删除标志                                                        │
  └────────────────────┴─────────────┴─────────────────────────────────────────────────────────────────────┘

  核心索引 idx_target_module_diff 直接支撑选题SQL：
  SELECT id FROM question_info
  WHERE target_level = 'CET4'
    AND module_type = 1        -- 词汇
    AND difficulty_level BETWEEN 3 AND 6   -- ELO自适应范围
    AND is_deleted = 0
    AND id NOT IN (最近7天已做题目)
  ORDER BY usage_count ASC
  LIMIT 10;

  为什么和 content 分表？
  - question_info 字段少、查询快，适合列表/筛选场景
  - question_content 含 TEXT/JSON 大字段，只在用户真正答题时才加载
  - 安全：前端请求列表时不会暴露正确答案

  ---
  5. question_content — 题目内容表

  负责功能： 题目正文存储（只在答题时加载）

  ┌────────────────┬──────────────┬───────────────────────────────────────────────────┐
  │      字段      │     类型     │                       作用                        │
  ├────────────────┼──────────────┼───────────────────────────────────────────────────┤
  │ question_id    │ BIGINT       │ 关联 question_info.id                             │
  ├────────────────┼──────────────┼───────────────────────────────────────────────────┤
  │ stem           │ TEXT         │ 题干（如 "The company ___ established in 2005."） │
  ├────────────────┼──────────────┼───────────────────────────────────────────────────┤
  │ options        │ JSON         │ 选项（["A. was","B. is","C. were","D. are"]）     │
  ├────────────────┼──────────────┼───────────────────────────────────────────────────┤
  │ correct_answer │ VARCHAR(500) │ 正确答案                                          │
  ├────────────────┼──────────────┼───────────────────────────────────────────────────┤
  │ analysis       │ TEXT         │ 解析（提交后展示，含知识点说明）                  │
  └────────────────┴──────────────┴───────────────────────────────────────────────────┘

  加载时机：
  用户点击"开始练习"
    → question_info 筛选出题目ID列表
    → 用户看到第N题时
    → 按 question_id 加载 question_content
    → 渲染 QuestionCard.vue 组件

  ---
  6. knowledge_mapping — 题目-知识点映射表

  负责功能： 建立题目与知识点的多对多关系

  ┌────────────────────┬────────┬──────────┐
  │        字段        │  类型  │   作用   │
  ├────────────────────┼────────┼──────────┤
  │ question_id        │ BIGINT │ 题目ID   │
  ├────────────────────┼────────┼──────────┤
  │ knowledge_point_id │ BIGINT │ 知识点ID │
  └────────────────────┴────────┴──────────┘

  为什么是多对多？ 一道题可能涉及多个知识点：
  题目："If I ___ you, I would study harder."
    → 知识点1: 虚拟语气（与现在事实相反）
    → 知识点2: be动词特殊用法（were代替was）

  唯一约束 uk_question_knowledge 防止重复映射。

  7. user_exercise_log — 答题记录表

  负责功能： 记录每次答题行为，支撑学习统计和事件驱动

  ┌──────────────────┬──────────────┬────────────────────────────────┐
  │       字段       │     类型     │              作用              │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ user_id          │ BIGINT       │ 用户ID                         │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ question_id      │ BIGINT       │ 题目ID                         │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ user_answer      │ VARCHAR(500) │ 用户提交的答案                 │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ is_correct       │ TINYINT      │ 1=正确, 0=错误                 │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ duration_seconds │ INT          │ 答题耗时（秒）                 │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ module_type      │ TINYINT      │ 模块类型（冗余，便于统计查询） │
  ├──────────────────┼──────────────┼────────────────────────────────┤
  │ trace_id         │ VARCHAR(50)  │ 全链路追踪ID（贯穿MQ→日志）    │
  └──────────────────┴──────────────┴────────────────────────────────┘

  数据流向——事件驱动核心：
  用户提交答案
    → ① exercise-service 写入 user_exercise_log
    → ② exercise-service 发送 MQ 消息（含 trace_id）
    → ③ learning-engine-service 消费消息
    → ④ 更新 user_memory_curve（遗忘曲线）
    → ⑤ 如果答错 → upsert user_error_book

  ---
  8. user_error_book — 错题本表

  负责功能： 错题收集、薄弱点分析、错题重练

  ┌───────────────────────┬──────────┬────────────────────────────┐
  │         字段          │   类型   │            作用            │
  ├───────────────────────┼──────────┼────────────────────────────┤
  │ user_id + question_id │ UNIQUE   │ 每人每題仅一条记录         │
  ├───────────────────────┼──────────┼────────────────────────────┤
  │ wrong_count           │ INT      │ 累计错误次数（每次答错+1） │
  ├───────────────────────┼──────────┼────────────────────────────┤
  │ last_wrong_at         │ DATETIME │ 最后答错时间               │
  ├───────────────────────┼──────────┼────────────────────────────┤
  │ is_resolved           │ TINYINT  │ 0=未解决, 1=已掌握         │
  └───────────────────────┴──────────┴────────────────────────────┘

  用途：
  - 薄弱点强化：统计 wrong_count 最高的知识点 → 选题策略加权
  - 错题重练：/exercise/error-book 接口查询 is_resolved=0 的题目
  - 掌握判定：连续答对N次后将 is_resolved 置为1

  三、learning_db（记忆引擎库）

  9. user_memory_curve — 艾宾浩斯遗忘曲线表

  负责功能： 间隔重复系统(SRS)核心，驱动每日复习任务

  ┌───────────────────────┬──────────┬──────────────────────────┐
  │         字段          │   类型   │           作用           │
  ├───────────────────────┼──────────┼──────────────────────────┤
  │ user_id + question_id │ UNIQUE   │ 每人每題一条遗忘记录     │
  ├───────────────────────┼──────────┼──────────────────────────┤
  │ mastery_level         │ INT      │ 掌握等级 1=陌生→5=精通   │
  ├───────────────────────┼──────────┼──────────────────────────┤
  │ next_review_time      │ DATETIME │ 下次复习时间（核心字段） │
  ├───────────────────────┼──────────┼──────────────────────────┤
  │ review_count          │ INT      │ 已复习次数               │
  ├───────────────────────┼──────────┼──────────────────────────┤
  │ last_review_at        │ DATETIME │ 最后复习时间             │
  └───────────────────────┴──────────┴──────────────────────────┘

  复习时间梯度（艾宾浩斯）：
  答对时升级:
    第1次答对 → mastery=2, next_review = T+1天
    第2次答对 → mastery=3, next_review = T+3天
    第3次答对 → mastery=4, next_review = T+7天
    第4次答对 → mastery=5, next_review = T+15天
    第5次答对 → mastery=5, next_review = T+30天

  答错时降级:
    复习时答错 → mastery=mastery-1, 重新按当前等级计算

  每日复习任务生成SQL：
  SELECT question_id FROM user_memory_curve
  WHERE user_id = ?
    AND next_review_time <= NOW()
  ORDER BY next_review_time ASC
  LIMIT 20;  -- 每日上限20题

  索引 idx_user_review(user_id, next_review_time) 就是为这个查询设计的，避免全表扫描。

  四、完整数据流总结

  ┌─────────────────────────────────────────────────────────────┐
  │                      用户注册 + 水平测试                       │
  │                                                             │
  │  注册 → sys_user 写入                                        │
  │  定级测试(20题) → ELO实时计算 → user_ability_radar 写入        │
  │       ↓                                                     │
  │  前端渲染能力雷达图(RadarChart.vue)                            │
  └─────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────┐
  │                        每日练习流程                            │
  │                                                             │
  │  ① 选题: 读 user_ability_radar.elo_score                     │
  │          → question_info 筛选合适难度题目                      │
  │          → question_content 加载题目正文                       │
  │                                                             │
  │  ② 答题: 用户提交 → user_exercise_log 写入                    │
  │          → 正确? 跳过 / 错误? → user_error_book upsert       │
  │                                                             │
  │  ③ MQ事件: exercise.complete 消息发送                         │
  │          → learning-engine 消费                              │
  │          → user_memory_curve 更新 next_review_time           │
  └─────────────────────────────────────────────────────────────┘
                                ↓
  ┌─────────────────────────────────────────────────────────────┐
  │                        每日复习流程                            │
  │                                                             │
  │  ① 查询: user_memory_curve WHERE next_review_time <= NOW()   │
  │  ② 取题: 按 question_id 加载 question_info + question_content │
  │  ③ 复习: 用户答题 → 答对升级/答错降级 → 更新 mastery_level     │
  │  ④ 首页展示: "今日待复习 N 题"                                 │
  └─────────────────────────────────────────────────────────────┘

  跨库关联原则： 微服务架构禁止跨库JOIN，所有关联通过 user_id 和 question_id 字段在应用层实现（OpenFeign
  调用或冗余字段）。
